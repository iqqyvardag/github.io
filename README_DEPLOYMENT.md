# TriOrigin Labs Website v0.1

GitHub Pages-ready static beta for `trioriginlabs.com`. No build process is required.

## Deploy

1. Back up the current repository.
2. Copy the contents of this folder into the repository root.
3. Commit and push to the GitHub Pages branch (commonly `main`).
4. In GitHub: Settings → Pages → Deploy from branch → select the repository root.
5. Keep the included `CNAME` file.
6. Test HTTPS, navigation, search, the label decoder, mobile menu, 404 handling and all source links.

## Important launch status

This is a functional front-end beta, not the complete 39-page content plan. It includes substantive starter pages, search and one working tool. Before representing it as a fully reviewed health publication:

- obtain named nutrition/clinical specialist review for health and evidence pages;
- expand the evidence review with a documented search protocol and trial-level table;
- complete the remaining launch content inventory;
- commission the final production vector logo;
- complete legal review of privacy and terms;
- add privacy-respecting analytics only after policy approval;
- add a newsletter only after a real provider and consent workflow are configured.

Run `python -m http.server 8000` inside this folder, then open `http://localhost:8000`.
