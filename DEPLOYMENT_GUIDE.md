# Deploying TriOrigin Website v0.3 with GitHub Desktop

1. In GitHub Desktop, open the `iqqyvardag.github.io` repository.
2. Choose **Repository → Show in Finder**.
3. Keep the hidden `.git` folder. Delete the other visible website files.
4. Copy everything inside the extracted `TriOrigin_Website_v0.3` folder into the repository folder.
5. Return to GitHub Desktop.
6. In **Summary**, enter `Launch TriOrigin Website v0.3`.
7. Click **Commit to main**, then **Push origin**.
8. Wait 2–5 minutes. Open `https://trioriginlabs.com` and hard-refresh with Command + Shift + R.

The repository root must directly contain `index.html`, `CNAME`, `assets`, `learn`, `evidence`, `about` and `legal`. Do not place them inside an extra outer folder.
